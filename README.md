# Прогнозирование спроса на такси

Проект посвящён прогнозированию почасового спроса на поездки такси по районам на основе исторических данных.

Основная задача: по предыдущим 72 часам истории спрогнозировать количество поездок на следующие 24 часа для каждого района.

## Структура проекта

```text
NETOLOGY_DIPLOM/
├── docs/                    пояснительная записка и презентация
├── graphics/                графики для отчета и презентации
├── research/                исследовательские и дополнительные ноутбуки
├── taxi-data/               сырые parquet-файлы с поездками
├── lstm_model_final.ipynb   основной ноутбук проекта
├── README.md                описание проекта
└── requirements.txt         зависимости
````

## Основной ноутбук

```text
lstm_model_final.ipynb
```

В ноутбуке реализованы:

* загрузка и объединение данных;
* агрегация поездок по часу и району;
* построение полной сетки `час × район`;
* добавление календарных, погодных, лаговых и rolling-признаков;
* разделение train/validation/test по времени;
* обучение baseline-моделей и LSTM;
* сравнение моделей по метрикам;
* анализ ошибок по горизонту прогноза и районам.

## Данные

Сырые данные должны лежать в папке:

```text
taxi-data/
```

Используются данные поездок такси и FHV-сервисов:

* Yellow Taxi;
* Green Taxi;
* High Volume FHV.

Дополнительно используются погодные данные Meteostat.

## Модели

В проекте сравниваются:

* `Naive`
* `DailySeasonal`
* `MovingAverage`
* `RidgeRegression`
* `LSTM_direct`
* `LSTM_V1_arch`
* `LSTM_residual`

Финальная модель: `LSTM_residual`.

## Результаты

Лучший результат показала модель `LSTM_residual`:

```text
MAE = 24.948
WAPE = 21.30%
```

Улучшение по MAE:

```text
относительно Naive: 63.65%
относительно DailySeasonal: 14.85%
относительно RidgeRegression: 21.89%
```
